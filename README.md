# 💈 СТАТЬ — барбершоп в Анапе

Одностраничный лендинг (landing page) барбершопа «СТАТЬ»: мужские стрижки, моделирование бороды, маникюр. Адаптивный дизайн в тёмной премиальной стилистике, сделан как одна HTML-страница без сборки и фреймворков.

🌐 **[Открыть демо](https://martynov-live.github.io/barbershop-stat/)**

## Разделы страницы

- **Hero** — обложка с названием, слоганом и кнопкой записи
- **Отзывы** — карточки реальных отзывов клиентов
- **Услуги** — прайс со стрижками, бородой и маникюром
- **Команда** — мастера барбершопа
- **FAQ** — частые вопросы клиентов
- **Контакты** — адрес (ул. Ленина, 154Б), часы работы (10:00–22:00), карта

## Особенности

- Полностью адаптивная вёрстка (десктоп + мобильный, отдельное мобильное меню)
- Семантический HTML5 и аккуратная структура секций
- Кастомные шрифты (Bebas Neue, Oswald, Inter) и единая система CSS-переменных для цветов и типографики
- SEO-разметка: `<title>`, `meta description`
- Плавная навигация по якорям

## Технологии

- **HTML5** — семантическая разметка, секции, навигация
- **CSS3** — переменные, fl/grid-вёрстка, адаптив, анимации
- **Vanilla JavaScript** — мобильное меню, интерактив (без фреймворков и зависимостей)

## Запуск локально

Откройте `index.html` в любом браузере — сборка и зависимости не требуются.
